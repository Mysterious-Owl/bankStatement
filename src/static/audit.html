Balance continuity

Each bank's running balance is walked day by day. Wherever the recorded transactions don't explain the change in balance, money moved that this ledger doesn't show — usually a missing statement. Unlike date gaps, this says exactly how much.

Possible duplicates

The same bank, day and amount in two different statement files. Overlapping exports of one period can format a reference number or description differently, so both copies survive the import and the transaction is counted twice. Ignore the extra copy, or mark the group as genuinely separate transactions.
